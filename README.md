# Web demos

Three demo web projects built as portfolio samples for **fictional businesses**. They are not client work.

| Demo | What it is | Stack |
|---|---|---|
| [Forma Studio](forma-studio/) | One-page landing for a 3D printing studio | HTML, CSS, JavaScript |
| [Studio Alder](studio-alder/) | Five-page site for an architecture studio | HTML, CSS, JavaScript |
| [Larkspur Orders](larkspur-orders/) | Order dashboard for a coffee roastery | React 19, TypeScript, Vite, Tailwind CSS 4 |

Live version: https://rwegeerg-afk.github.io/web-demos/

Fonts are open source (SIL OFL); licence files sit next to the font files.
